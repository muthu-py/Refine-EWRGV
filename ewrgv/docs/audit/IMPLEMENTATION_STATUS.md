## Cross-cutting observations

- These modules are not automatically composed into one pipeline by `ResearchPipeline` for the current KG signal route. The route sequence is a user/UI-driven series of requests.
- `ResearchPipeline` is a synchronous orchestration abstraction with injectable dependencies and a distinct legacy/LLM gap detector; it should not be mistaken for the persistent API workflow.
- There are no durable queue/worker integrations found (e.g. Celery/Redis). FastAPI `BackgroundTasks` are in-process.
- The config describes local BM25/vector artifact paths and local embedding option; the relational migration set is PostgreSQL-specific. Effective deployment configuration must be supplied by environment.
- Existing tests are substantial in file count but file presence does not prove execution or coverage. This audit did not run them.
